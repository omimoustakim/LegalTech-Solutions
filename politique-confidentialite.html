Politique de Confidentialité

En vigueur au 3 septembre 2026. Conformément aux législations relatives à la protection des données à caractère personnel.

1. Collecte des Données

Les données personnelles collectées via le formulaire de contact de ce site sont les suivantes :

  • Nom complet ou Raison Sociale
  • Numéro WhatsApp professionnel
  • Type de projet
  • Description de votre projet

Ces données sont collectées uniquement dans le but de répondre à votre demande de diagnostic gratuit.

2. Finalité du Traitement

Vos données personnelles sont traitées pour :

  • Répondre à vos demandes de renseignements
  • Vous proposer une feuille de route technique et juridique
  • Assurer le suivi de votre projet

3. Durée de Conservation

Vos données personnelles sont conservées pour une durée maximale de 12 mois à compter de la dernière interaction, sauf obligation légale contraire.

4. Droits des Utilisateurs

Conformément aux législations en vigueur, vous disposez des droits suivants :

  • Droit d'accès : obtenir une copie de vos données
  • Droit de rectification : corriger vos données inexactes
  • Droit de suppression : demander la suppression de vos données
  • Droit d'opposition : vous opposer au traitement de vos données

Pour exercer ces droits, contactez-nous à : omimoustakim@gmail.com

5. Sécurité

Nous mettons en œuvre les mesures techniques et organisationnelles nécessaires pour protéger vos données contre tout accès non autorisé, altération, divulgation ou destruction.
